Viết bot bằng C++17 hoặc Python 3

Sửa hàm trong mã mẫu: C++ dùng Move chooseMove(const BoardState& state), Python dùng choose_move(state). Trạng thái bàn cờ và nước hợp lệ có sẵn; hệ thống xử lý input/output.

Giá trị hàm trả về

C++ trả về một Move trong state.legal_moves; Python trả về một dict trong state["legal_moves"] hoặc dict chỉ có piece_id, to. Không viết main(), không tự đọc input hoặc in kết quả.

05
◷

Kiểm tra trạng thái và thi đấu

Theo dõi trạng thái bài nộp trong “Lịch sử nộp bài”. Chỉ bot sẵn sàng mới được ghép đấu; encounter chạy theo lượt do ban tổ chức xác nhận. Bot trả sai định dạng, nước không hợp lệ hoặc quá 1,5 giây một lượt sẽ bị xử thua ván.

Mã mẫu và trạng thái bàn cờ

C++17: hàm và kiểu dữ liệu có sẵn
// API: chooseMove(const BoardState& state) returns Move.
// state.pieces, state.legal_moves, state.at(x, y).
// state.board[y][x]: optional<Piece>; coordinates 0..8.
// No main() or input/output code.
Move chooseMove(const BoardState& state) {
    // Thay bằng thuật toán của bạn.
    return state.legal_moves.front();
}

state.side: phe của bot; state.move_number: số nước; state.pieces: toàn bộ quân còn sống. state.at(x, y) trả về const Piece* hoặc nullptr. state.board[y][x] là std::optional<Piece>. Tọa độ từ 0 đến 8.

Piece: id, side, type, x, y. Move: piece_id, from, to, capture; capture là std::optional<std::string>. Không cần tự khai báo các kiểu này.

Python 3: hàm và trạng thái dạng dict
# API: choose_move(state) returns a legal move dict.
# state: side, move_number, board_size, pieces, legal_moves.
# Piece coordinates: 0..8. Judge handles input/output.
def choose_move(state):
    # Thay bằng thuật toán của bạn.
    return state["legal_moves"][0]

Đọc bàn cờ qua state["pieces"], phe qua state["side"] và nước hợp lệ qua state["legal_moves"]. Mỗi lượt gọi hàm một lần. Có thể thêm hàm phụ và import thư viện chuẩn.

Di chuyển và ăn quân

Bàn cờ 9×9. Mỗi lượt đi một ô theo một trong tám hướng; Xanh đi trước. Đấm thắng Kéo, Kéo thắng Lá, Lá thắng Đấm. Quân cùng loại hoặc không khắc chế được sẽ chặn ô.

◎

Thắng, hòa và xếp hạng

Thắng khi ăn hết một loại quân đối thủ hoặc đưa quân tới đích (Bắc: a1, Nam: i9). Lặp thế cờ ba lần hoặc đủ 200 nước chưa phân thắng bại thì hòa. Điểm ván: thắng 1, hòa 0,5, thua 0. Vòng bảng: mỗi encounter 2 ván; điểm trận thắng 3, hòa 1, thua 0. Knockout: 6 ván chính, tối đa 4 ván phụ.
