LUYỆN TẬP KHÔNG QUOTA

Cải thiện bot trên máy bạn.

Cho bot mới đấu với bot mẫu, phiên bản cũ hoặc bot bạn bè chia sẻ. Xem từng nước, observation, log và replay. Source ở trên máy bạn; không cần tài khoản, database hay lượt Practice của BTC.

1. Lấy mã nguồn và mở local lab

Cần Python 3.10 trở lên. Cài thêm g++ hỗ trợ C++17 nếu thử bot C++; Python không cần compiler C++ hay thư viện pip.

git clone https://github.com/Ppt05/Laptrinhmang_G8.git
cd Laptrinhmang_G8
python -m app.local

Mở địa chỉ local bên dưới sau khi terminal báo sẵn sàng.

Mở local lab ↗

2. Chọn hai đối thủ và thử chiến thuật

Mở source .py/.cpp của Bot A và Bot B, hoặc dùng First, Greedy, Random. Bấm Biên dịch & tạo ván, rồi Đi 1 lượt hoặc Chạy. Dùng Đổi phía trước khi tạo ván tiếp theo để thử cả hai phía.

3. Debug và xem lại

Tab Đầu vào hiển thị observation của nước đang chọn. Tab Log nhận stderr: Python dùng print(..., file=sys.stderr), C++ dùng std::cerr. Tải replay để giữ lại ván lỗi; mở replay không chạy lại code bot.

Muốn kiểm tra trong sandbox?

Native chạy code với quyền tài khoản máy bạn, phù hợp bot do bạn viết. Với code chưa tin cậy hoặc khi cần thử giới hạn giống BTC, cài Docker và chạy:

docker build -f sandbox/Dockerfile -t oantuti-sandbox:dev .
python -m app.local --backend docker

Local lab dùng cùng engine và SDK với worker. Native không áp dụng giới hạn RAM/CPU của Docker. Kết quả local không đổi Elo; khi bot đã ổn, dùng Practice trên worker BTC hoặc nộp vào Tournament.
